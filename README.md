# FinPilot

AI-powered personal finance decision-support agent.

## Problem

Financial information is often scattered across bank statements, bills,
subscriptions, and expense records. FinPilot helps users understand their
financial activity and make more informed everyday financial decisions.

## Features

- Upload transaction statements and expense records
- Automatic transaction categorization
- Recurring payment detection
- Subscription detection
- Unusual spending detection
- Monthly income and expense analysis
- Budget tracking
- Financial goals
- Upcoming financial obligations
- AI-powered financial Q&A
- Monthly financial summaries

## Architecture

- Frontend: React / Next.js
- Backend: FastAPI
- Database: PostgreSQL
- AI: LLM-powered decision-support layer
